1. ภาพรวมของหน้าจอนี้

  • วัตถุประสงค์: ใช้สำหรับบันทึก แก้ไข และค้นหาข้อมูลใบคำขอสมัครเข้าเป็นสมาชิกสหกรณ์ (ทั้งกรณีสมัครใหม่ สมาชิกเดิมที่ลาออกแล้วกลับมาสมัครใหม่ หรือการโอนย้ายมาจากสหกรณ์อื่น) รองรับการบันทึกข้อมูลส่วนบุคคล ข้อมูลการทำงาน ข้อมูลการส่งค่าหุ้นรายเดือน ข้อมูลบัญชีธนาคารสำหรับรับ-จ่ายเงิน/เงินปันผล/การหักเงินเดือน ข้อมูลบุคคลในครอบครัว/ผู้รับผลประโยชน์ ข้อมูลที่อยู่อื่นๆ ข้อมูลการโอนย้ายจากสหกรณ์อื่น และการเชื่อมโยงรูปถ่าย/เอกสารผู้สมัคร
  • ไฟล์ต้นทางหลัก: ws_mem_reqappl.aspx, ws_mem_reqappl.aspx.cs, DsMain.ascx, DsMain.ascx.cs, DsAddress.ascx, DsAddress.ascx.cs, DsFamily.ascx, DsFamily.ascx.cs, DsMoneytr.ascx, DsMoneytr.ascx.cs, DsTransfer.ascx, DsTransfer.ascx.cs, DsAccountMain.ascx, DsAccountMain.ascx.cs
  • ระบบที่หน้าจอนี้สังกัด: ระบบสมาชิกและหุ้น (mbshr)

2. ลำดับขั้นตอนการทำงานของหน้าจอนี้

  1. การเข้าสู่หน้าจอและตั้งค่าเริ่มต้น: เมื่อเปิดหน้าจอ (!IsPostBack) ระบบจะเรียกเมธอด Refresh() เพื่อกำหนดค่าเริ่มต้น ได้แก่ MEMBCAT_CODE = "10" (สมาชิกสามัญ), APPL_DOCNO = "AUTO", APPLY_DATE = state.SsWorkDate, NATIONALITY = "ไทย", APPLTYPE_CODE = "10", address_set_code = "00" (ที่อยู่ปัจจุบัน), EXPENSE_CODE = "TRN", pauseshare_flag = 0 พร้อมทั้งสร้างรายการบัญชีเริ่มต้นใน dsMoneytr 2 รายการ ได้แก่ รายการเงินปันผล (TRTYPE_CODE = "DVAV1", MONEYTYPE_CODE = "DEP") และรายการหักเงินเดือน (TRTYPE_CODE = "KEEP1", MONEYTYPE_CODE = "SAL"` หรือตามค่า `EXPENSE_CODE` ของสังกัด) และสร้าง Token สำหรับเชื่อมโยง iframe รูปภาพผู้สมัคร (`wd_fom_upload_image.aspx`)
  2. การนำเข้าข้อมูลผู้สมัคร:
    • กรณีอ่านข้อมูลจากบัตรประชาชน (Smart Card): ผู้ใช้คลิกปุ่ม b_Smart_Card ระบบส่งคำขอไปยัง Local Service http://localhost:1888/ismartcard เมื่ออ่านข้อมูลสำเร็จจะเรียก PostSmartCard เพื่อนำข้อมูลเลขบัตรประชาชน, คำนำหน้า, ชื่อ-สกุล (ไทย/อังกฤษ), เพศ, วันเกิด, ที่อยู่ มากรอกลงในฟิลด์ต่างๆ โดยอัตโนมัติ และตรวจสอบความถูกต้องของเลขบัตรประชาชน
    • กรณีค้นหาใบคำขอเดิมมาแก้ไข: ผู้ใช้คลิกค้นหาจากแถบเมนู (MenubarOpen) เปิดหน้าต่างค้นหา wd_mem_request.aspx เมื่อเลือกใบคำขอ ระบบจะส่ง appl_docno กลับมา และเรียก PostApplDocno เพื่อดึงข้อมูลเดิมจากตาราง MBREQAPPL, MBREQAPPLADDRESS, MBREQAPPLFAMILY, MBREQAPPLMONEYTR
    • กรณีสมัครใหม่ด้วยตนเอง: ผู้ใช้เลือกกลุ่มสมาชิก (MEMBCAT_CODE) และกรอกเลขประจำตัวประชาชน (CARD_PERSON)
  3. การตรวจสอบและคำนวณอัตโนมัติระหว่างกรอกข้อมูล:
    • เมื่อกรอกเลขบัตรประชาชน (CARD_PERSON): ตรวจสอบ Check Digit (Mod 11), ตรวจสอบสมาชิกภาพเดิม (CheckCardPerson) หากเป็นสมาชิกอยู่แล้วหรือมีใบคำขอรออนุมัติจะไม่อนุญาต, ตรวจสอบจำนวนครั้งที่เคยลาออกเทียบกับ MBUCFCATEGORY.MAXAPPL_TIME และระยะเวลาหลังลาออกเทียบกับ MBUCFCATEGORY.RETURNAPPL_PERIOD หากผ่านเกณฑ์และเคยเป็นสมาชิกมาก่อน ระบบจะดึงข้อมูลสมาชิกเดิมจาก MBMEMBMASTER มาแสดงให้อัตโนมัติ (RetreiveApplDocnomaster) พร้อมคำนวณสิทธิ์ซื้อหุ้นโอนย้ายประเภทสมาชิก (CheckTranMembtype)
    • เมื่อเลือกคำนำหน้าชื่อ (PRENAME_CODE): ระบบกำหนดเพศ (SEX) ให้อัตโนมัติ
    • เมื่อระบุวันเกิด (BIRTH_DATE): คำนวณอายุ (memb_age) และตรวจสอบอายุขั้นต่ำตาม MBUCFMEMBTYPE.REGIS_AGE, คำนวณวันเกษียณอายุ (RETIRE_DATE), และหากอายุครบ 60 ปีขึ้นไปจะเปิดให้เลือก "งดส่งหุ้น" (pauseshare_flag) ได้
    • เมื่อระบุเงินเดือน (SALARY_AMOUNT): คำนวณค่าหุ้นฐานขั้นต่ำ (PERIODBASE_VALUE) และค่าหุ้นส่งรายเดือนเริ่มต้น (PERIODSHARE_VALUE) ผ่าน WebUtil.GetMinMaxShareBase
    • เมื่อระบุค่าหุ้นต่อเดือน (PERIODSHARE_VALUE): ตรวจสอบไม่ให้ต่ำกว่าหุ้นฐาน ไม่เกินเพดานสูงสุด และเป็นไปตามกฎของสมาชิกที่เคยลาออกหรือเกษียณอายุ
    • เมื่อเลือกสังกัด (MEMBGROUP_CODE): กำหนดรูปแบบการชำระเงินของรายการเรียกเก็บ (KEEP1) ตาม MBUCFMEMBGROUP.EXPENSE_CODE
    • เมื่อเลือกฝ่ายงาน (DEPARTMENT_CODE): ค้นหาและแสดงชื่อหน่วยเลือกตั้ง (groupelec_desc) จาก ELCMAPELECTION
    • เมื่อระบุตำบล (TAMBOL_CODE): ดึงรหัสไปรษณีย์ (POSTCODE) จาก MBUCFTAMBOL อัตโนมัติ
    • สามารถกดปุ่ม "คัดลอกที่อยู่" ในส่วนที่อยู่อื่นๆ (PostDupAdd) หรือครอบครัว (PostDupFamily) เพื่อคัดลอกที่อยู่หลักมาใช้งาน
  4. การบันทึกข้อมูล (SaveWebSheet):
    • ผู้ใช้กดปุ่มบันทึก (Save) ระบบตรวจสอบความครบถ้วนฝั่ง Client ผ่าน JavaScript Validate()
    • เซิร์ฟเวอร์ทำงานในเมธอด SaveWebSheet():
      • ตรวจสอบความถูกต้องของข้อมูลครอบครัว (ความสัมพันธ์, เลขบัตรประชาชน 13 หลัก)
      • กรณีแก้ไขใบคำขอ (APPL_DOCNO != "AUTO"): ตรวจสอบว่าสถานะต้องเป็นรออนุมัติ (APPL_STATUS == 8) เท่านั้น จึงจะบันทึกการอัปเดตข้อมูล (ExecuteType.Update) ลงตาราง MBREQAPPL, MBREQAPPLADDRESS, MBREQAPPLFAMILY, MBREQAPPLMONEYTR
      • กรณีเพิ่มใบคำขอใหม่ (APPL_DOCNO == "AUTO"): ตรวจสอบใบคำขอซ้ำ, ขอเลขที่เอกสารใหม่ผ่าน WebUtil.GetLastDocumentNo("MBAPPLDOCNO", true, false), บันทึกข้อมูลใหม่ (ExecuteType.Insert), บันทึกการผูกรูปภาพผ่าน WebUtil.SaveImageREQ, และอัปเดตเลขที่เอกสารล่าสุดใน CMDOCUMENTCONTROL
      • แสดงข้อความผลการบันทึกสำเร็จ และรีเซ็ตหน้าจอเพื่อพร้อมรับรายการถัดไป

5. สิทธิ์การใช้งาน

Role/Permission ฟังก์ชันที่ควบคุม เงื่อนไข
ผู้ใช้งานระบบสมาชิกและหุ้น (mbshr user) เข้าถึงหน้าจอใบสมัครสมาชิก บันทึกใบคำขอ แก้ไขใบคำขอ และค้นหาข้อมูล ผ่านการยืนยันตัวตนในระบบ GCOOP และมีสิทธิ์ในระบบงาน mbshr (state.SsApplication = "mbshr")
สิทธิ์การควบคุมระดับสาขา/สหกรณ์ (Coop Control) การมองเห็นและบันทึกข้อมูลใบคำขอแยกตามสหกรณ์ กรองและบันทึกข้อมูลตามรหัสสหกรณ์ที่เข้าใช้งาน (state.SsCoopControl, state.SsCoopId)
สิทธิ์การแก้ไขใบคำขอ การแก้ไขข้อมูลใบคำขอที่บันทึกไปแล้ว จำกัดให้แก้ไขได้เฉพาะใบคำขอที่มีสถานะ APPL_STATUS = 8 (รออนุมัติ) เท่านั้น ไม่อนุญาตให้แก้ไขใบคำขอที่อนุมัติหรือยกเลิกแล้ว
