Library: pcdivavg.pbl Entry: of_prc_estdivavg_opt Target Table: YRRPTESTDIVAVG Ancestor: n_cst_process_base

1. ภาพรวม (Overview)

วัตถุประสงค์หลักของ NVO Object n_cst_proc_divestm ใน PowerBuilder Library pcdivavg.pbl คือ การประมวลผลประมาณการเงินปันผล (Dividend) และเงินเฉลี่ยคืน (Average Return) ล่วงหน้าประจำปีของสหกรณ์


กระบวนการนี้ช่วยให้ฝ่ายจัดการและคณะกรรมการของสหกรณ์สามารถกำหนดเรทอัตราปันผลและเฉลี่ยคืนจำลองเป็นช่วงๆ (เช่น ปันผล 5.00% - 6.00% ขยับทีละ 0.25%) เพื่อทดลองคำนวณยอดเงินรวมที่จะต้องจ่ายจริง เปรียบเทียบผลกระทบต่อสภาพคล่องและงบการเงินก่อนเสนออนุมัติจ่ายจริงในการประชุมใหญ่ประจำปี

Trigger & Execution Context

ถูกเรียกใช้งานจาก Window ประมวลผลประมาณการปันผลเฉลี่ยคืน (เช่น w_pop_div_estdivavg_option) โดยส่งผ่านตัวเลือกคอนฟิกหลักทาง istr_process.arg1 (XML Option) และ istr_process.arg2 (XML Loan Type Option)
