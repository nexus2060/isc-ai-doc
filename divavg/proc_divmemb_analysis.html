1. ภาพรวม (Overview)

Object n_cst_proc_divmemb ใน PowerBuilder Library C:\GCOOP_ALL\CORE\GCOOP\PBProcess\pcdivavg.pbl เป็น NVO หลักที่ทำหน้าที่ประมวลผลตั้งข้อมูลสมาชิก, หุ้น, และหนี้เงินกู้เพื่อคำนวณเงินปันผลและเงินเฉลี่ยคืนประจำปีสำหรับระบบ Core Banking ของสหกรณ์

บทบาทหลักในระบบ Core Banking:
  • คัดกรองและสร้างทะเบียนสมาชิกที่มีสิทธิ์ปันผล/เฉลี่ยคืนลงตาราง YRBGMASTER
  • ประมวลผลฐานหุ้นยกมาและหุ้นระหว่างปีคำนวณเงินปันผลทั้งแบบ รายวัน (DAY) และ รายเดือน (MTH)
  • คำนวณดอกเบี้ยกู้จ่ายสะสมเพื่อเฉลี่ยคืนลง YRBGLONMASTER
  • คัดลอกช่องทางการจ่ายเงินปันผลจากปีก่อนหน้าลง YRREQMETHPAY / YRREQMETHPAYDET

2. ลำดับการทำงาน (Workflow)

  1. Init Parameter: นำเข้า XML Option อ่านค่าคงที่ระบบปันผลผ่าน Service
  2. Step 1 Clear Old Data: เรียก of_prc_memb_clr() เพื่อลบข้อมูลประมวลผลเดิมในตาราง YRBG*
  3. Step 2 Gen Dividend Members: เรียก of_prc_memb_master() เพื่อสร้างสมาชิกสิทธิ์ปันผลลง YRBGMASTER
  4. Step 3 Process Shares: เรียก of_prc_memb_shr() -> of_prc_memb_shr_mas() และแยกตามประเภทคำนวณ (DAY / MTH)
  5. Step 4 Process Loans: เรียก of_prc_memb_lon() เพื่อรวมดอกเบี้ยเงินกู้ลง YRBGLONMASTER
  6. Step 5 Process Payout Method: เรียก of_prc_memb_methpayold() ตั้งวิธีจ่ายเงินจากปีเก่า
  7. Commit Transaction: บันทึกข้อมูล (COMMIT USING sqlca) และอัปเดตสถานะสำเร็จลง CMPROCESSING

3. ขั้นตอนการประมวลผลอย่างละเอียด (Detailed Processing & Code Reference)

3.0 ฟังก์ชันหลัก of_gen_period (Entry Point ในการคำนวณงวดเดือน)

Signature: public function integer of_gen_period (date ad_startdate, date ad_datadate)

ทำหน้าที่แปลง ad_datadate (วันที่เคลื่อนไหวหุ้น) ให้เป็น งวดเดือนทางบัญชี (1 ถึง 12) โดยอ้างอิงจาก ad_startdate (วันเริ่มรอบปีบัญชีของสหกรณ์)

public function integer of_gen_period (date ad_startdate, date ad_datadate);
integer		li_accmonth, li_month, li_monthdif, li_monthstart

li_monthstart	= month( ad_startdate)
li_month		= month( ad_datadate )

li_monthdif	 	= li_monthstart - 1

if li_month < li_monthstart then
	li_accmonth = ( li_month+12 ) - li_monthdif
else
	li_accmonth = li_month - li_monthdif
end if

return li_accmonth
end function

3.1 ฟังก์ชันควบคุมหลัก of_prc_memb

เป็น Entry Point หลัก ควบคุมลำดับการประมวลผล Step 1 ถึง Step 5 และจัดการ Transaction (COMMIT/ROLLBACK)

try
	this.of_pgstep( 1, li_maxstep )
	this.of_prc_memb_clr(lds_constant,lds_mbopt)
	
	this.of_pgstep( 2, li_maxstep )
	this.of_prc_memb_master(lds_constant,lds_mbopt)

	this.of_pgstep( 3, li_maxstep )
	this.of_prc_memb_shr(lds_constant,lds_mbopt)

	this.of_pgstep( 4, li_maxstep )
	this.of_prc_memb_lon(lds_mbopt)
	
	if li_metholdflg = 1 then
		this.of_pgstep( 5, li_maxstep )
		this.of_prc_memb_methpayold(lds_mbopt)
	end if
	
	commit using sqlca ;
catch( exception lthw_memb )
	rollback using sqlca ;
	this.of_pgerror( iex_exception.text )
end try

3.3 การสร้างทะเบียนสมาชิกสิทธิ์ปันผล of_prc_memb_master

คัดเลือกสมาชิกสิทธิ์ปันผลลงตาราง YRBGMASTER ตามเงื่อนไข memset_code (REG, SHR, CSM) และอัปเดต Flag งดปันผลจาก YRREQREFRAIN

3.4 การประมวลผลหุ้น of_prc_memb_shr / of_prc_memb_shr_mas

อัปเดตหุ้นยกมาใน YRBGINFO, สร้าง YRBGSHRMASTER, YRBGSHRSTATEMENT, และคำนวณปันผลย้อนหลังหุ้นปีก่อนใน YRBGSHRSTATEMENTBF พร้อมเรียกฟังก์ชันปัดเศษเงินปันผล ftcm_roundmoney

3.5 การคำนวณปันผลหุ้นรายวัน of_prc_memb_shr_day

คำนวณจำนวนวันสะสม (daysafter) ระหว่างวันที่หุ้นเคลื่อนไหวจนถึงสิ้นปีบัญชี อัปเดตลง YRBGSHRSTATEMENT

3.6 การคำนวณปันผลหุ้นรายเดือน of_prc_memb_shr_mth & of_prc_memb_shr_mth_mod

เรียกใช้ of_gen_period() เพื่อหางวดเดือนทางบัญชี (1-12) ตรวจสอบวัน Cutoff การซื้อหุ้นประจำเดือน และปรับยอดยกมาตามการถอนหุ้นย้อนหลัง

3.7 การประมวลผลหนี้สำหรับเฉลี่ยคืน of_prc_memb_lon

รวมยอดดอกเบี้ยเงินกู้ชำระสะสมจาก LNCONTSTATEMENT บันทึกลง YRBGLONMASTER และอัปเดตการงดเฉลี่ยคืนรายสัญญาจาก YRREQREFRAINLOAN

3.8 การตั้งข้อมูลวิธีจ่ายปันผลจากปีเก่า of_prc_memb_methpayold

คัดลอกข้อมูลช่องทางการรับเงินปันผล/เฉลี่ยคืนจาก YRDIVMETHPAY ปีก่อนลง YRREQMETHPAY และ YRREQMETHPAYDET
